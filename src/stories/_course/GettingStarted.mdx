# Figma SDS, customized

[Figma's Simple Design System](https://github.com/figma/sds) (SDS), customized for the course. Figma's components, tokens and stories are unchanged. Added on top: these pages, a *Code* page for every component, Storybook 10 with its MCP server, and a Figma library generated from this code.

**Links:** [Code on GitHub](https://github.com/christinevall/figma-sds-custom) · [What was customized](https://github.com/christinevall/figma-sds-custom/blob/main/COURSE-NOTES.md) · [Where Figma differs from the code](https://github.com/christinevall/figma-sds-custom/blob/main/figma/GAPS.md)
